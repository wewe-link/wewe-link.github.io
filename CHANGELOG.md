# Changelog — проект «На ощупь»

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/).

---

## [1.0.0] — 2026-07-11

### Добавлено
- Первая версия сайта-медиакита (на основе `mediakit_na_oschup.html`)
- `index.html` + `styles.css` — стили вынесены в отдельный файл
- Git-репозиторий с первым коммитом

### Изменено (рефакторинг)
- **Этап 1**: все inline-стили (`style="..."`) вынесены в CSS-классы: `.subtitle`, `.divider--short`, `.list-title`, `.list`, `.grid-2-col`, `.lyric--accent`, `.mt-1_5`, `.footer-divider`, `.footer-hint`, `.footer-text`
- **Этап 2**: улучшена семантика HTML — `<nav>` вместо `<div>` для навигации, обёртка `<main>`, `<footer>` вместо секции с контактами, `aria-label` на кнопках карусели и навигации
- **Этап 3**: CSS-переменные для хардкодных значений — `--border-color`, `--accent-bg`, `--carousel-btn-bg`, `--carousel-btn-hover`, `--shadow`, `--divider-gradient`
- **Этап 4**: добавлены favicon (SVG-эмодзи) и Open Graph-теги для шаринга в соцсетях

## [1.1.0] — 2026-07-11

### Добавлено
- Touch-свайп для каруселей (работает на мобильных устройствах)
- `loading="lazy"` для изображений (кроме первого — оно preload)
- `preload` для первого изображения (`photo_1.jpg`)
- Обработчик `resize` для пересчёта активной навигационной точки

### Изменено
- `pageYOffset` заменён на `window.scrollY` (современный стандарт)

## [1.2.0] — 2026-07-11

### Добавлено
- Анимация появления секций при скролле (fade-in + translateY через Intersection Observer)

### Исправлено
- Плавное перелистывание картинок в карусели (fade через opacity + transition)
- Вёрстка кнопок карусели — круглые (56×56px), backdrop-filter, scale при наведении
- Печатная версия (Ctrl+P) — скрыты карусели, сброшены анимации, увеличен padding

## [1.3.0] — 2026-08-16

### Исправлено
- Намеренно ухудшено качество изображений, нормализован размер, изменены имена

## [1.4.0] — 2026-08-16

### Добавлено
- `script.js` — JavaScript вынесен из `index.html` в отдельный файл (подключается через `defer`)
- Обработка ошибок парсинга `data-images` и защита от отсутствующих элементов карусели
- Предзагрузка всех изображений карусели через `new Image()` при инициализации

### Изменено
- Карусель переработана на кроссфейд (fade) с двумя слоями изображений — новое фото плавно проявляется поверх старого

### Исправлено
- Резкое переключение изображений в карусели: активный слой теперь определяется динамически, плавный кроссфейд работает на каждом переключении

## [1.5.0] — 2026-08-16

### Изменено
- Изменены шрифты и размер заголовков
- Изменено содержание index.html, учтены предложения Лизы

### Исправлено
- Двойной скроллбар: `overflow-x: hidden` на `html`/`body` заменён на `overflow-x: clip` (не создаёт scroll container) — остался один вертикальный скроллбар
- Диспропорция карусели при text zoom: высота карусели переведена с фиксированных `vh` на `clamp()` с rem-границами — карусель масштабируется вместе с текстом
- «Разъезжание» секций при text zoom: `min-height: 100vh` заменён на `clamp(40rem, 100vh, 80rem)` — секции сжимаются под контент при уменьшении масштаба
