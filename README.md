# «На ощупь» — медиакит проекта

Одностраничный сайт-медиакит пластического спектакля **«На ощупь»** — постановки о том, как двигаться, когда пути не видно. Проект создан студентами НИУ ВШЭ при поддержке **HSE Dance** — крупнейшей студенческой танцевальной организации России.

Сайт размещён на GitHub Pages и представляет собой статическую страницу на чистом HTML, CSS и JavaScript без внешних зависимостей.

## О спектакле

«На ощупь» — это contemporary-постановка о студенчестве как о большом переходе: из одного города в другой, из детства во взрослую жизнь, из представлений о себе — в реальность. Спектакль говорит на языке танца о том, что порой тяжело сказать вслух, и напоминает, что даже в неуверенности и тревоге мы не одиноки.

Премьера состоялась в апреле 2026 года на сцене Культурного центра ВШЭ: **300+ зрителей** с **25+ факультетов**, **500+ регистраций**, **4 открытых мастер-класса**.

## Возможности сайта

- **Навигация по секциям** — фиксированные точки-индикаторы справа, плавный скролл к секциям
- **Две фотокарусели** — кроссфейд-переключение изображений, кнопки «вперёд/назад»
- **Touch-свайп** — поддержка свайпов на мобильных устройствах
- **Анимация появления секций** — fade-in + translateY при скролле (Intersection Observer)
- **Адаптивная вёрстка** — брейкпоинты 1024px, 768px, 480px
- **Печатная версия** — при Ctrl+P карусели и навигация скрываются
- **Open Graph-теги** — корректный превью при шаринге в соцсетях
- **Lazy-loading изображений** — ускорение загрузки страницы
- **Favicon** — SVG-эмодзи 👐

## Технологии

- **HTML5** — семантическая разметка (`<nav>`, `<main>`, `<footer>`, `<section>`)
- **CSS3** — CSS-переменные, `clamp()`, `backdrop-filter`, media queries, print-стили
- **JavaScript (vanilla)** — Intersection Observer, `scrollIntoView`, touch-события, кроссфейд-карусель

Без сборщиков, фреймворков и внешних зависимостей.

## Запуск локально

Проект — статический сайт, для запуска достаточно открыть `index.html` в браузере:

```bash
# Вариант 1: просто открыть файл
start index.html

# Вариант 2: локальный сервер (рекомендуется)
python -m http.server 8000
# затем открыть http://localhost:8000
```
